Open the updated app

  1. In your running BridgePit, open Settings, scroll to the bottom and choose Quit BridgePit. Confirm, then close its old browser tabs.
  2. Open the downloaded installer. Drag BridgePit into Applications and replace the older app. Launch it from Applications and reload the dashboard.
  3. Check http://127.0.0.1:8787/api/version shows 1.4.22. If you deliberately use a different port, use that port instead.

Run the connection test

  1. Open Settings → Test TradingView delivery → Prepare connection test.
  2. Follow its three short instructions: create a separate one-time price alert in TradingView, copy the test message and webhook URL, then create the alert. Keep BridgePit and Tailscale running.
  3. Return to BridgePit and look for Test message received. If it has not arrived, open No confirmation yet? and check the price alert's event and Webhook status in TradingView.

The message is valid for ten minutes. Preparing another test replaces it. You can delete the one-time price alert after its message arrives.
